# Chicken Shish visual source library

The PNGs in `sources/` are the original ImageGen output files used as visual studies and asset masters. They are kept at source resolution. Browser assets in `charcoal-demo/assets/menu/` and `charcoal-demo/assets/shish/` are compressed WebP derivatives. The uploaded restaurant references were visible in the conversation, with no original attachment files available for archival in this workspace.

## Serving standard

Use a white hinged HP10 box with a camera close to 45 degrees. With Chips variants have chips beneath the chicken. Customer-selected salad sits beside it. Griddled white onion and red and green peppers sit amongst the chicken. Pitta is placed towards the rear. The final composition keeps the food visible. Use the same viewpoint, box and chicken piece scale for all variants. Large contains 50% more chicken than Medium as confirmed by the restaurant. The number of sprites illustrates relative size and is not a sold piece count or a gram weight.

## Layer preparation

The open and closed box are photographic cutouts. The front rim is a mask over the same open-box image, aligned on the same canvas so food passes behind it. Individual pieces and ingredients come from the alpha atlases. Web exports retain transparency. Use the existing product configuration as the authoritative source for selections and prices. The Chicken Shish profile sets the position and motion of each layer, while the shared scene renderer and sauce assets remain reusable.
